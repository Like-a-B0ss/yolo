# Frontend

Interface React + TypeScript para imagens, webcam e reprodução de vídeos do YouTube
com os quadros anotados pelo YOLO em tempo real.

## Executar

```powershell
npm install
npm run dev
```

O Vite encaminha HTTP e WebSocket de `/api` para `http://127.0.0.1:8000`. Consulte o
[README principal](../README.md) para iniciar o backend e conhecer o fluxo completo.
